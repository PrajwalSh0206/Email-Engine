# Email Engine Frontend

The React and Vite frontend for Email Engine provides provider sign-in and a mailbox dashboard for Inbox, Sent, and Deleted folders.

## Commands

```powershell
npm install
npm run dev
npm run build
npm run lint
npm run preview
```

The frontend expects the backend at `http://localhost:8000` by default. See the repository-root [README](../README.md) for provider configuration and Docker setup.
